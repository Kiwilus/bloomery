# Contributing to Bloomery

Thanks for your interest in contributing to Bloomery!  
Bloomery is a lightweight, minimalist build system for Java written in Rust.  
I started it because I wanted something simple – similar to Maven, but without the complexity.

Contributions of all kinds are welcome: bug reports, feature ideas, documentation improvements, and code.

## How to contribute

1. Open an Issue first (especially for bigger changes)
2. Fork the repo
3. Create a branch (`feature/...` or `fix/...`)
4. Make your changes
5. Open a Pull Request and describe what you did

## Guidelines

- Keep it simple and minimalist
- Please test your changes first
- Write clear commit messages and comments in English

Feel free to open an issue if you have questions.
